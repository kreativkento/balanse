
  # Balanse Wellness Hub

  ## Project Description / Purpose

The Balanse Wellness Management System is a web-based system designed to support the daily operations of a wellness and fitness center. It helps manage clients, staff, coaches, schedules, bookings, memberships, payments, announcements, media content, and other wellness center activities.

The system is designed for six user roles: Administrator, Staff, Coach, Media Staff, Client/Student, and Developer. Each role has specific permissions based on its responsibilities.

  ## Setup Instructions

Before running the system locally, make sure the following are installed: `Git` `Node.js`  `npm` `A web browser` `Required database software or database service used by the project`
